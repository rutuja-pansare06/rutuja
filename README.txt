RUTUJA PANSARE PORTFOLIO WEBSITE

Files:
1. index.html - Website content and structure.
2. style.css - Website design and styling.

HOW TO USE:
1. Upload index.html and style.css into the same folder in your GitHub repository.
2. Keep both filenames unchanged.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select your main branch and the /(root) folder, then Save.
6. Wait for GitHub Pages to publish your website.

Make sure index.html and style.css stay together so the styling loads correctly.
